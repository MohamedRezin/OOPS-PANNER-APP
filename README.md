# # Java OOPS Banner App

A Java-based Object-Oriented Programming (OOP) learning project that demonstrates the progressive development of an ASCII banner application through multiple structured use cases.

This project was created as a step-by-step exploration of core Java and OOP concepts, beginning with simple console output and gradually evolving into a modular, reusable system using arrays, methods, classes, and collections.

---

## Overview

The application renders the word "OOPS" as an ASCII-art banner in the console while progressively introducing important programming concepts and software design improvements across different use cases.

Each branch represents a separate stage in the application's evolution.

---

## Learning Objectives

This project explores:

- Java fundamentals
- Object-Oriented Programming concepts
- Arrays and loops
- String manipulation
- Modular programming
- Static methods
- Inner classes
- Collections Framework
- HashMap usage
- Code organization and maintainability

| Use Case | Concept Introduced |
